# 0.9.2 — English and Simplified Chinese

The interface now defaults to English. Switch to Simplified Chinese under **Settings → Learning Coach → Language / 语言**. The choice persists across restarts. Settings, navigation, course and assessment forms, errors, trace views, and newly generated coaching instructions use the selected language.

User notes, course names, source quotes, answers, and saved history remain unchanged. Switching language does not rename output folders or migrate existing exports. New configurations use `Learning Coach` and `Learning Coach/Traces`; existing configured paths remain intact.

True/false validation accepts existing Chinese questions and new English questions. Language-specific model prompts use separate cache keys. The UI language control is disabled during an active learning request.

The root README, security policy, publishing guide, current release notes, and issue template are in English. An English user guide and contribution guide were added; the Chinese user guide remains available.

This is a pre-release preparing for 1.0, not a community publication. Real-device tests, actual-provider quality review, the seven-day trial, and complete multi-device learning-state synchronization remain open acceptance work.

Validation: 90 automated tests and 27 isolated Obsidian flows passed, including English defaults, live switching, persisted language after restart, unchanged drafts, local true/false grading, trace export, and 320 / 390 / 768 px English layouts. Build, smoke, package checks, and credential-pattern scans also passed. Model calls used a fixture service, not the user's real provider.
