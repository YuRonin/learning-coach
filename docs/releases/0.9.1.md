# 0.9.1 — Agent traces for the trial

Added agent traces, enabled by default and stored in a normal vault folder. Settings allow a custom folder, a readable viewer, and a seven-day export. Records link actions, model requests, local caching, structure checks, question review, local grading, and persistence. Retries create separate files linked by the same operation digest.

Logs accept a fixed field whitelist and omit keys, service URLs, and learning content. Trace write failure does not block learning and appears in settings. Unexpected app closure can leave an unfinished record. Devices generate separate files; actual synchronization depends on the user's sync setup.

Passed at this release: 86 automated tests, build and smoke checks, and 25 isolated Obsidian flows. Model calls used a fixture service. Mobile layouts were emulated, not tested on a real iPhone. The seven-day trial, actual-provider quality checks, and device acceptance remained open. This was not labeled as final 1.0.
