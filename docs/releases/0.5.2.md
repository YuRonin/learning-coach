# 0.5.2 — Per-course question types

Courses can enable single choice, true/false, multiple choice, and short answer in any non-empty combination. Choose adaptive distribution or fixed proportions totaling 100%. The even-distribution control assigns integer proportions.

Each unit offers a session-only override. The study view shows the frozen policy; later course edits do not alter an active session. Diagnostic, remediation, and next-question responses are validated against that policy. Unsupported types are blocked with the session retained for retry.

Fixed proportions use cumulative successfully displayed questions. Skipped and unanswered questions count as displayed; failures and retries do not. Progress and mastery evidence are separate. Short sessions are balanced across later sessions. Historical display counts are not guessed for old versions.

Reviews use the current course policy. If the original type is disallowed or does not fit the fixed allocation, a new question for the same point is generated. Failure remains retryable instead of falling back to a disallowed type.

## Data and validation

Data format 3 saves the complete session policy and cumulative baseline. A one-time `data.pre-0.5.2.json` snapshot preserves the earlier state. Existing settings, original answers, and sessions remain; old sessions without a snapshot retain their earlier behavior. Downgrading requires disabling the plugin, privately saving current data, and restoring the matching snapshot. Backups contain unencrypted keys.
