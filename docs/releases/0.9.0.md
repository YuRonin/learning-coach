# 0.9.0 — Course learning acceptance build

This version exercised the course learning loop. It did not satisfy the original plan's final 1.0 release gates.

## Changes

- Stable unit identifiers and knowledge points with confirmation, editing, merging, splitting, deactivation, and prerequisites. New evidence attaches to points; old records do not automatically raise a new point's status.
- Persistent daily tasks with budgets, reasons, progress, and session links. Ten-minute plans, deferral, skipping, and continuation are supported. Changed material needs reconfirmation.
- Reviews normally generate a different question. Local checks reject near-duplicates and answer leaks; short-answer and multiple-choice questions receive independent model review. Uncertain results are blocked. An allowed original-question fallback is available as weaker evidence after generation failure.
- Unit assessments preview scope and counts, hide feedback until submission, and report evidence and gaps without inventing exam scores. Post-submission reassessment retains earlier grades and supports retry.
- Pasted syllabus, goal, and question material can be mapped to knowledge points. Optional model suggestions only update a preview. Courses can be archived and their learning records cleared without deleting source notes.
- Persistent generation/reviewer cache: seven days, 50 entries, about 1 MB. Hits make no request. Connection/model/temperature changes clear it; grading and reassessment are not cached.
- Settings display provider-reported input, output, and cached tokens without estimating unreported savings or cost.

## Upgrade

Requires Obsidian 1.13.7 or later. Replace only the three runtime files and retain personal data. Reading older data creates `data.pre-0.9.0.json`; subsequent saves use format 4. Unclassified historical answers keep their old association instead of becoming evidence for newly created points.

Disable the plugin and privately back up `data.json` and `data.backup.json` before rollback. Use a matching old runtime and pre-upgrade snapshot; newer records are not in that snapshot. Do not open newer data with an older plugin.

The separate `learning-cache.json` may contain source excerpts and questions. Clearing it does not delete answers, but the file still needs to remain private.

## Validation at this release

- 81 automated tests, including migration, knowledge isolation, budgets, review deferral, assessment allocation, quality rejection, and cache boundaries.
- Type checks, build, bundle loading, and migration/recovery smoke checks passed.
- 24 isolated real-Obsidian flows with 33 local fixture HTTP requests and no page errors, including cold/warm cache and clearing.
- Mobile emulation at 320, 390, and 768 px, landscape, large text, and both themes. No real-phone results.
- One desktop synthetic benchmark: 3,000 sessions, 500 points, about 4.17 MB; serialization about 6 ms, parsing 25 ms, review computation 11 ms, planning 39 ms, and file writing 13 ms. These are not mobile performance guarantees.

Real DeepSeek generation/reviewer evaluation, real cross-day course study, iPhone/Android checks, screen-reader testing, and the seven-day trial remained open. The build was installed locally with user configuration and history retained; it was not publicly released or submitted to the community directory.
