# Studying a course with Learning Coach

## Set up

Install the plugin, open its settings, and select **English** or **Simplified Chinese** under **Language / 语言**. English is the default. Enter your own base URL, API key, and model identifier, then test the connection.

## Prepare a course

Add a course from a notes folder. Exclude indexes and unrelated material in the preview. Set your exam date if relevant, daily study budget, and allowed question types. Fixed proportions must total 100%; adaptive mode stays within the types you enable.

Each note becomes a unit. Extract local knowledge-point candidates, inspect the continuous source quotes, and confirm the points you want to practice. The optional model split tool suggests a preview; it does not save or confirm learning evidence for you.

Syllabus excerpts and personal requirements can be pasted with their source. Link them to knowledge points yourself or request candidate mappings, then confirm. A notes outline or imported question is not automatically an official syllabus or exam question.

## Study, assess, and review

Plan tasks on Today or start directly from a knowledge point. Try answering independently. Use a hint or explanation when needed; that help remains recorded with your answer. Identify a difficulty if useful, then practice a new scenario.

Use a unit assessment to check several confirmed points together. Preview its coverage and question counts, answer independently, and submit before viewing feedback. It reports evidence rather than an invented exam score.

Return for delayed review. Provisionally stable requires independent correct answers to different questions at least a day apart. If a generated question is wrong, request reassessment or invalidate it. Previous answers and assessments remain available.

## Pause and change devices

Pause before closing or switching devices and wait for saving and synchronization. The plugin can restore pending work and drafts, but it does not merge simultaneous changes from two devices. Ordinary trace and summary files may sync even when plugin data does not. Syncing plugin data also transfers its unencrypted connection settings.

## Seven-day feedback

In settings, open Agent traces or export the last seven days. Note the version, device, language, steps that failed, and approximate time so a trace can be located. Check exported files before sharing; do not send the entire plugin data directory. Real iPhone and Android validation is still pending.
