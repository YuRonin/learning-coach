# 用学习教练学习一门课程

> 从 0.9.2 起默认界面为英文。在设置 → Learning Coach → Language / 语言 中选择“简体中文”，即可按本指南的中文入口操作。切换不会改写历史内容或移动已有目录。

本指南对应 0.9.0 开发验收版。先选一章试用，确认题目和原文符合你的学习目标，再扩展到整门课。

## 准备课程

在设置中填写服务地址、访问密钥和模型名称，测试连接。到“课程 → 添加课程”选择文件夹，预览纳入的笔记，排除索引、空白和答案合集。每天的时间、考试日期及优先级可以按实际情况填写。

每篇笔记是一个单元。展开单元，点击“从笔记整理知识点”，再进入“编辑与确认知识点”。候选来自笔记标题，在本地整理，不需要模型。检查每个知识点的名称与连续原文引用，确认后才能纳入今日任务。

标题太粗时可以手动拆分，也可以选中一个知识点让模型提出拆分候选，逐项核对后保存；只发送该点的引用。重复内容可以合并。先预览再保存；旧知识点停用并保留历史，新知识点重新建立证据。可以指定前置知识点，系统会拒绝循环关系。必要时从“查看原文”回到引用位置。

文件改名或移动后保留单元标识；文件缺失时重新关联。修改材料会提示更新，重新整理并确认后再学；旧记录仍保留，但不会直接证明新版内容已学会。

## 配置题型

单选、多选、判断、简答独立勾选，至少一种。只想做单选，可以取消其余题型。

“按固定比例出题”要求比例合计 100%，也可平均分配。三题小轮次不一定刚好符合比例，后续轮次按累计展示数补足。跳过计入展示，生成失败不计入；展示数不代表得分。

“教练根据作答调整”只能从已勾选题型中选择。本轮临时设置不改课程默认，进行中的学习始终保留开始时的规则。章节检验开始前单独预览整数题数；教练调整模式在章节检验中均衡分配启用题型。

## 安排今天

到“今日”设置总预算，或点“今天只有十分钟”。计划优先考虑到期复习、薄弱点，再安排已确认的新知识；复习积压不会无限挤占新学。

任务显示理由与估计时长，可以开始、继续、延后或跳过。提前结束但没完成目标，不会被标成已完成。计划按本地日历日期记录，同时保存当时的时区；跨日重新安排，不追改昨天的计划。

活跃时长是估计值，会忽略长时间空闲，不能作为精确计时器。临近考试时会提示尚无证据的知识点，不承诺一定来得及学完。

## 练习与补弱

知识点学习可在先讲后练与先测再学之间切换。单选、多选、判断点选即可；多选必须完整选对。简答支持文字说明和计算步骤。

“确定 / 不确定 / 猜的”可以不填。答错后可以选择自己认为的错因，再点“讲清缺口，再换题练习”。错因是用户自报，不是一次错误得出的能力诊断。连续受阻时先回看原文、前置内容，或暂停。

提示、直接讲解和普通追问分别记录。看到答案后的正确回答、猜中的回答、原题复习都需要继续检验。普通追问的帮助程度仍依赖模型判断，不能保证完全准确。

客观题在本地判分，断网也能提交已有题目。模型评价失败会保留原始回答，重试不会增加一条新的作答。暂停后忽略迟到结果，退出后可从任务或记录继续。

## 复习与章节检验

知识点复习默认生成新情境，合并成一个复习条目。复习间隔为 1、3、7、14、30 天；同一天重复答对不加速升级，使用帮助或回答有缺口会回到一天后。

换题失败时可以重试；允许的原题也可主动用来复习，但会标为较弱证据。若原题型已被禁用，就不能回退到它。

章节检验选择已确认的知识点和题数，预览后开始。中途不显示评价、提示和答案；交卷后显示每个知识点的回答、依据及缺口，不虚构考试总分。未完成的题会保留标记，已有正确证据不清零。到“今日”重新安排即可纳入发现的缺口。

考纲、目标或题目资料可粘贴到课程中，手动选择关联知识点，也可让模型建议对应项，再核对确认。原文和关联结果保留，没有提供考纲时页面会注明没有考试权重依据。导入的题目文本不会自动还原成正式试卷。

## 查看证据、处理争议

“暂时稳定”需要不同题目、相隔至少一天的独立正确记录。状态按知识点隔离，不能因为同一笔记里一道题答对就让所有知识点变稳定；旧版未归类记录也不会自动获得新关联。

题目有问题时报告作废，原回答与原因保留，状态和复习重新计算；误操作可恢复。一般学习中的评价异议可以请求模型复核。章节检验交卷后可在报告逐题复核，也可从记录报告作废。失败后重试沿用原始回答和复核理由。

导出的 Markdown 不会随之后的复核或作废自动修改，需要重新导出。课程归档停止调度；归档后的清理只移除插件内关联记录，原笔记、导出及备份要分别管理。

## 缓存、升级和手机

缓存默认开启，保存通过校验的出题与审题结果，七天内最多五十项、约一兆字节。命中时不发请求；评分和复核不缓存。设置里可查看、关闭和清空，本地命中与服务端词元缓存分别显示。

更新只替换三个运行文件，保留个人数据。0.9.0 使用格式 4，旧数据升级前保留 `data.pre-0.9.0.json`。密钥、数据备份和缓存都不应公开上传，详见 README。

手机可从命令面板打开学习教练。先等待同步完成再换设备，不要同时编辑同一轮学习。移动布局已模拟验证，iOS 与 Android 真机测试仍待完成。
