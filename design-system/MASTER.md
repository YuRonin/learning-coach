# 学习教练界面规范

本文件是界面设计的唯一基准。适用于电脑侧栏、手机标签页、设置、记录与后续新增功能。风格：安静、清楚、适合长期阅读的中文学习工作台。

## 参考与选择

参考 [UI UX Pro Max skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/dcc40ff5133ef78276117db0cc34e7b83cc8aeba/.claude/skills/ui-ux-pro-max/SKILL.md)，版本提交 dcc40ff5133ef78276117db0cc34e7b83cc8aeba。已阅读移动端专业规则和无障碍、触控、性能检查。

查询 `education learning calm accessible --design-system` 返回儿童教育的黏土风格与展示型页面，不符合成人笔记学习和 Obsidian 深色主题，不采用。缩小查询为 `minimalism accessible productivity --domain style`，命中简约工具风格；采用清晰层级、少装饰、统一强调色与双主题。具体中文排版、青绿配色和学习流程由本项目确定，不宣称是 skill 原样生成。

## 中文文案

- 名称统一为“学习教练”，导航固定为“今日 / 学习台 / 记录”。不用英文副标题、英文口号或中英混排装饰。
- 设置字段使用“服务地址 / 访问密钥 / 模型名称”；进阶项使用“请求超时 / 生成温度”等中文名称。
- 专有名称（Obsidian、OpenAI、Ollama）、真实模型名称、服务地址、文件名、必要代码标识可保留原名。不要翻译用户的笔记、原文引用或代码。
- 模型讲解、题目、评价默认简体中文；必要英文专业术语附中文说明。
- 按钮使用明确动作：“提交回答”“给点提示”“发送追问”“完成本轮”。不要使用“确定”“继续”承载不明确的动作。
- 错误说清发生了什么、内容是否保留和下一步能做什么。不要用未经验证的“已掌握”“精通”或虚构学习数据鼓励用户。

## 视觉令牌

在 styles.css 的 `.lc-root, .lc-settings` 中维护；组件不得另创配色体系。

| 项目 | 规范 |
| --- | --- |
| 强调色 | 浅色 #216b5e，深色 #90d7bb |
| 主按钮文字 | 浅色白色，深色 #142820 |
| 讲解背景 | 浅色 #edf5f1，深色 #203b32 |
| 正文、次要文字、面板、边框 | 沿用 Obsidian 语义主题变量 |
| 字体 | Obsidian 界面字体及系统中文字体；不下载远程字体 |
| 正文 | 跟随界面字号，移动端跟随正文字号；输入框至少 16px |
| 行高 | 正文 1.7，讲解 1.85 |
| 间距 | 4 / 8 / 12 / 16 / 24；卡片内边距 16 |
| 圆角 | 卡片 12，控件 8；不使用超大胶囊卡片 |
| 按钮高度 | 电脑至少 44px，手机至少 48px |
| 动效 | 140ms 色彩反馈；减少动态效果开启时停用 |

不使用装饰渐变、玻璃模糊、立体玩具风格、表情图标或外部图片。未来新增图标使用 Obsidian 内置线框图标，文字旁装饰图标对读屏隐藏。

## 页面与操作

- 今日：未连接时优先引导连接；已有学习优先恢复；其次到期复习和选笔记。不展示空洞的统计仪表盘。
- 学习台：来源与真实进度 → 学习路线（折叠）→ 最新讲解 → 当前题或评价 → 本轮互动（折叠）→ 暂停、结束与导出。不要把聊天历史堆在当前题之前。
- 进度条仅表示已评价题数，不表示掌握度。超过计划的加练允许继续，进度条填充至多 100%。
- 作答卡只有“提交回答”用实心主按钮。提示、讲解、追问和跳过使用次要按钮，保持明确间距。
- 记录：先展示日期、来源、目标与状态，证据按需展开；空状态提供开始学习入口。
- 设置：连接模型 → 学习偏好 → 高级设置（折叠）。测试连接结果持续显示；更改连接字段后提示重新测试。
- 输入有可见标签；状态不只依靠颜色。导航暴露当前页面，异步状态有读屏提示，焦点轮廓清晰。
- 页内刷新保留滚动位置；不同导航页分别保存滚动位置。按钮和输入不依赖悬停、右键或快捷键才能使用。

## 后续改动流程

1. 先确认属于哪个既有页面与组件，复用其令牌和文案。
2. 新组件若无法复用，先在本文件记录用途、状态与差异，再实现；不要另建无关联风格文件。
3. 不覆盖模型、笔记和记录数据来做视觉演示，使用独立测试库与本地测试模型。
4. 在浅色、深色检查正文和按钮对比度，目标至少 4.5:1；自定义主题仍需单独检查。
5. 验证 320 / 390 / 768 像素及横屏、长文本、放大字体与减少动态效果；不能出现页面横向溢出或操作被遮挡。
6. 跑类型检查、现有测试、产物加载和真实 Obsidian 流程验收。模拟手机须标注模拟，不能写成真机通过。

## 0.4.0 验收范围

中文标题与设置、双主题、真实题数进度、单主操作、可展开互动、持续连接反馈、空记录引导和页面滚动记忆。UI 不改变学习证据和评分调度的含义。
